# City of Portland documents

Documents produced by City of Portland bureaus or officials about PPS rightsizing that were not sent to the PPS Board
(letters to the Board go in `sources/correspondence/`). Stored as published; provenance in each folder's `_manifest.json`.

Cite as `[CITY:<path under sources/city/> p.<page>]`, page = PDF page (the `.pdf.txt` file separates pages with \f).
These are City analyses, not PPS facts; say so when citing them.
