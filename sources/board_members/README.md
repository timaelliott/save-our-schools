# Documents written by individual PPS Board members

Proposals and memos that a Board member published personally (not as a Board action and not posted on BoardBook).
They state one director's views and figures; PPS staff have not necessarily vetted them. Say so when citing them.
Provenance is in each folder's `_manifest.json`. Living documents are re-fetched into the same file names through
`tools/safe_copy.py`, so earlier versions are kept in `_prior/`.

Cite as `[BRD:<path under sources/board_members/> p.<page>]`, with page = PDF page (`.pdf.txt` separates pages with \f).
